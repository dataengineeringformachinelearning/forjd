# Preferences

> **Superseded.** FORJD is API-only. Theme and soft UI preferences live on
> **[deml.app](https://deml.app)** via deml-ui (`data-theme` + ThemeService).
> Historical suite preference packs (`suite-preferences-v1`, forjd.co landing)
> are retired with the product frontend.
