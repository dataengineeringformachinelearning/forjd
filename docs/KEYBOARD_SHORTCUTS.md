# Keyboard shortcuts

> **Superseded.** FORJD is API-only (no product frontend). Partner UX and
> keyboard chords live on **[deml.app](https://deml.app)** (control plane) and
> community docs. This file is historical.

| Chord | Action | Surface |
|-------|--------|---------|
| `⌘K` / `Ctrl+K` | Search / command palette | deml.app |
| `/` | Open search (when not typing) | deml.app |
| `Esc` | Close overlay | deml.app |
| `?` | Keyboard shortcuts help | deml.app |
| `⌘,` / `Ctrl+,` | Preferences / theme | deml.app |

Backend HTML shells on [backend.forjd.co](https://backend.forjd.co) are splash +
API docs only — they do not mount product shortcuts.
